# Changelog

## 1.0.0-alpha.2

- Public developer preview release of Goat WebView Flutter plugin.
- Dual-mode WebView engine supporting Android (Chromium WebView) and iOS (WKWebView).
- Bi-directional MethodChannel IPC bridge with 210 standardized API actions.
- Headless WebView rendering, session isolation, and mock testing support.
- Prewarmed instance recycling and multi-tenant cookie isolation.

## 1.0.0

- Initial release baseline.
