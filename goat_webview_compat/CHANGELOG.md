# Changelog

## 1.0.0-alpha.2

* Public developer preview release of `goat_webview_compat`.
* Drop-in compatibility adapter for migrating from `flutter_inappwebview` 5.x and 6.x to Goat WebView.
* Support for `InAppWebView`, `InAppWebViewController`, `InAppWebViewSettings`, `URLRequest`, `WebUri`, and `CookieManager`.
* 10 architectural performance and security guarantees (G1–G10) with zero retained config state.
