Bridge API Reference

The Goat WebView Native Bridge provides 185 standardized native actions categorized across 24 core capabilities.

Summary of Action Categories​

CategoryActions CountExample ActionsDescription
1. Device & Haptics3GET_DEVICE_INFO, HAPTIC_FEEDBACKDevice model, OS, battery, screen metrics, anonymous installGuid, and tactile feedback.
2. Storage & Sandboxing8STORAGE_SET, STORAGE_GET, SECURE_STORAGE_SET, SECURE_STORAGE_GETKey-value preferences, AES-256 GCM encrypted enclave secrets, and account isolation.
3. Cookies & Web Storage6COOKIE_GET, COOKIE_SET, COOKIE_REMOVE, WEB_STORAGE_GET_QUOTA_USAGE, WEB_STORAGE_CLEARRFC 6265 cookie management and Web Storage quota accounting.
4. In-App OAuth & Auth4START_OAUTH_SESSION, CANCEL_OAUTH_SESSION, HTTP_AUTH_SAVE_CREDENTIAL, HTTP_AUTH_CLEAR_CREDENTIALSCustomTabs / ASWebAuthenticationSession OAuth flows and HTTP Basic/Digest credential storage.
5. Navigation & UI12NAVIGATE_BACK, SET_NAV_BAR_TITLE, SET_NAV_BAR_COLOR, EXPAND_BOTTOM_SHEET, COLLAPSE_BOTTOM_SHEETNative navigation bars, bottom sheets, predictive back gestures, and system theme colors.
6. Filesystem Sandboxing10FS_WRITE_FILE, FS_READ_FILE, FS_MKDIR, FS_RMDIR, FS_LIST_DIR, FS_STAT, FS_EXISTSSandboxed file I/O with Zip Slip and path-traversal guards.
7. Native Dialogs & Feedback6SHOW_TOAST, HIDE_TOAST, SHOW_MODAL, SHOW_ACTION_SHEET, SHOW_LOADING, HIDE_LOADINGNative alerts, modals, action sheets, loading HUDs, and anti-spam cooldown protection.
8. Motion & Sensors10START_ACCELEROMETER, START_COMPASS, START_GYROSCOPE, START_DEVICE_MOTIONSensor data streams with coalesced event throttling (50ms).
9. Location & Geofencing7GET_LOCATION, CHOOSE_LOCATION, START_GEOFENCE, LIST_GEOFENCES, EVALUATE_GEOFENCEHigh-accuracy GPS, map pickers, and circular geofence boundary monitoring.
10. Camera, Media & QR6SCAN_CODE, CHOOSE_MEDIA, PREVIEW_IMAGE, CHOOSE_FILES, CANCEL_FILE_CHOOSERBarcode/QR scanning, gallery/camera pickers, and multi-file choosers.
11. Audio Playback4AUDIO_PLAY, AUDIO_PAUSE, AUDIO_STOP, AUDIO_SEEKBackground audio playback with lifecycle management.
12. Network & Connectivity6API_REQUEST, GET_NETWORK_TYPE, IS_CONNECTED, UPLOAD_FILE, DOWNLOAD_FILE, WEBSOCKET_CONNECTQuic/HTTP3 networking, byte counting, SSL pinning, and WebSocket streams.
13. Bluetooth Low Energy7START_BLE_SCAN, CONNECT_BLE_DEVICE, READ_BLE_CHARACTERISTIC, WRITE_BLE_CHARACTERISTICBLE scanning, GATT connection, and characteristic read/write.
14. NFC Discovery5START_NFC_DISCOVERY, STOP_NFC_DISCOVERY, READ_NFC_NDEF_MESSAGE, NFC_WRITE_TAGNDEF message decoding and NFC tag writing.
15. Push Notifications9GET_PUSH_TOKEN, PUSH_REQUEST_PERMISSION, PUSH_SET_BADGE, SUBSCRIBE_PUSH_TOPICPush token registration, badge updates, and topic subscription.
16. Web3 & Payments7WEB3_CONNECT_WALLET, WEB3_SIGN_TRANSACTION, OPEN_INVOICE, GET_PURCHASE_PRODUCTSCrypto wallet signing and in-app purchase product queries.
17. Binary Message Ports4CREATE_BINARY_PORT, POST_BINARY_MESSAGE, READ_BINARY_MESSAGE, CLOSE_BINARY_PORTZero-copy ArrayBuffer binary IPC channels.
18. Permissions & Settings5CHECK_PERMISSION, REQUEST_PERMISSION, GET_SETTING, OPEN_SETTING, AUTHORIZETwo-stage rationale permission priming and settings deep-linking.
19. Performance & Tracing10START_TRACE, STOP_TRACE, GET_TRACES, GET_APM_METRICS, GET_MEMORY_METRICSW3C OpenTelemetry distributed tracing and APM instrumentation.
20. Ahead-Of-Time Bytecode4PRECOMPILE_BYTECODE, IS_BYTECODE_WARM, CLEAR_BYTECODE_CACHE, GET_BYTECODE_STATSV8 Code Cache and JavaScriptCore bytecode compilation.
21. Subpackages & Native Views8LOAD_SUBPACKAGE, IS_SUBPACKAGE_CACHED, EMBED_NATIVE_VIEW, UPDATE_NATIVE_VIEW_BOUNDSDynamic subpackage loading and composited native view embedding.
22. Benchmarks & Discovery5GET_API_CAPABILITIES, REGISTER_CAPABILITY, GET_STARTUP_BENCHMARK_REPORTRuntime capability probing and boot benchmark metrics.
