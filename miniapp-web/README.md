# Goat WebView Mini-App Web JS SDK

The official JavaScript & TypeScript client library for Goat WebView mini-apps.

## Overview

`@goat/miniapp-web` provides a robust, type-safe interface for web applications running inside Goat WebView containers on Android, iOS, React Native, and Flutter.

## Features

- **141-Action Bridge Parity**: Full bidirectional communication with the host application.
- **Custom Hooks**: React hooks for Navigation Bar, Bottom Sheet, Insets, Haptics, and Lifecycle events.
- **Security & Sandboxing**: Built-in origin verification and safe message dispatching.
- **TypeScript First**: Full typings for all bridge requests, responses, and events.
